# **My Learning-LM **👨‍🎓🧑‍💻📊 

**Language 🇬🇧 🇲🇲 🇺🇸 **

Prototype frontend for **My Learning LM** — a teen-friendly, NotebookLM-inspired study companion with Burmese-first UI and English toggle.

## အထက်တန်းကျောင်းသူ/သား များစာလေ့လာရာတွင်လွယ်ကူစေရန် NotebookLMကို inspection ယူပြီး Myanmar mini Version ဖန်တီးထားပါသည်။📊👨‍🎓

# Run locally
🇲🇲 သင့်device တွင် Run ပြီးလျှင် home ဖြင့်ထွက်၍ သင့်ရဲ့ Chrome or Browser မှ main search bar တွင် 👉 index.html ကိုရိုက်ထည့်ပါ။ ထိုအခါ သင်run ထားသော My Learning LM app ကိုတိုက်ရိုက်အသုံးပြုနိုင်ပါပြီ။

🇺🇸 Run it on your device and exit home, then type 👉 index.html in the search bar of your Chrome or main Browser. Then you can directly access the My Learning LM app that you can used easily.
