# Drift You

A modern mock Android location-route simulation application built with Kotlin + Jetpack Compose.

## Features
- Select start and end points directly on the map canvas.
- Simulate smooth route traversal between selected points.
- Movement modes: Car, Bicycle, and Walking.
- Adjustable speed slider.
- Toggle between Road and Satellite visual map modes.
- Polished dark-themed UI with modern cards and chips.

## Note
This is a **mock simulator** intended for UX/prototyping and demo flows. It does not integrate real map providers or OS-level mock-location injection.
